Set undistortion poses for the pipeline by sampling tf.

Aligns the frame stamp to the 10ms grid and samples the last 200ms. Only samples newer than the last fed stamp are queried to avoid looking up the same poses twice on overlapping frames.

Parameters
[in]stampTimestamp of the incoming frame
